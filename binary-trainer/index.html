WHAT IS BINARY?

Binary is base-2 — a number system that uses only two digits: 0 and 1. Humans use base-10 (ten fingers, ten symbols: 0–9). Computers use base-2 because electronic switches have exactly two states: on or off.

Each digit is called a bit (binary digit). Every position is double the one to its right — just like how each position in base-10 is 10× the last.

Base-10: hundreds · tens · ones
            100 · 10 · 1

Base-2: ...· 8 · 4 · 2 · 1
        = 2³· 2²· 2¹· 2⁰
⚡

HOW COMPUTERS READ IT

Every chip is built from transistors — microscopic switches etched onto silicon. A transistor is either conducting electricity (1) or blocking it (0). Your CPU has billions of them.

8 bits = 1 byte — the basic unit of computer memory. One byte can represent 2⁸ = 256 different values (0–255). Everything from text to images to machine code is bytes at rest.

1 bit → 2 values (0 or 1)
4 bits → 16 values (0–15)
8 bits → 256 values (0–255)
32 bits → 4 billion values
64 bits → 18 quintillion values
🌍

WHERE YOU SEE IT

Binary is the substrate of everything digital — you interact with it constantly without seeing the 0s and 1s.

  • Text: 'A' = 65 = 01000001. Every character is a number (ASCII / Unicode).
  • Colors: #FF5733 = red 255, green 87, blue 51 — three 8-bit numbers.
  • Networking: IP 192.168.1.1 is four 8-bit numbers. Subnet masks are binary AND operations.
  • Files: 1 KB = 1024 bytes = 2¹⁰. KB → MB → GB are all powers of 2.
  • Audio: CD quality = 16-bit samples at 44,100 per second per channel.
  • Permissions: Unix chmod 755 = rwxr-xr-x = 111 101 101 in binary.
🔡

HEX & THE BINARY FAMILY

Binary gets long fast — 255 takes 8 digits. So engineers use hexadecimal (base-16) as a compact shorthand. One hex digit represents exactly 4 bits.

1111 1111₂ = FF₁₆ = 255₁₀
0001 0000₂ = 10₁₆ = 16₁₀
1010 1011₂ = AB₁₆ = 171₁₀

You'll see hex in:

  • CSS colors: #1A2B3C
  • Memory addresses: 0x7fff5fbff8c0
  • SHA hashes: deadbeef...
  • MAC addresses: 00:1A:2B:3C:4D:5E
